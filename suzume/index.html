🀄 すずめ雀ヘルパー試作

軍曹（XREAL AURA）向け「TACTICAL ASSIST / Suzume-Jong」の Web 試作。手牌をタップで入れる → 捨て牌と待ちを助言。AURA 実機が届く前に、助言エンジンの正しさをここで固める。

1. 設定（ドラ表示牌・親）

ドラは「表示牌そのもの」がドラになる（一般の麻雀と違う）よ。表示牌が赤牌のこともあるから、その場合は下の「表示牌が赤」にもチェック（その赤は場に残らない）。手牌の赤いドラは赤+ドラで1枚2点。親がアガると +2 点（ただし5点条件には含まない）。

ドラ: 未設定

2. 手牌（5枚＝待ち分析／6枚＝捨て牌相談）

下のパレットから牌をタップして追加（タップで手牌から外せる）
0 / 6 枚

数牌は通常・赤の2ボタン。赤は各数字1枚だけ、中は全部が赤扱い（1枚1点）。同じ牌は4枚まで。

3. 場を見る（カメラ＋捨て牌入力 → 危険牌予測）

場の写真を撮って見ながら、各プレイヤーの捨て牌を入力するのが今の現実解だよ（牌の自動認識は軍曹の実機フェーズで検証）。捨て牌が入ると、6枚時の助言に「その牌を切るとロンされる確率」の予測が付く。

この写真を見ながら、下で捨て牌を入力してね。写真から牌を自動で読む処理はまだ入っていない（正直ベース）。

自分が一度捨てた牌ではロンできない（フリテン）。相手が捨てた牌は、その相手には確実に安全。危険度は「見えている牌を全部差し引いた山から相手の手を推定する」モンテカルロ計算で、相手の打ち筋までは読まない近似だよ。

この試作で検証していること

① すずめ雀の得点計算（順子1点／刻子2点／赤・ドラ各1点／タンヤオ1点／チャンタ2点／役満3種、5点以上でアガリ、親+2は条件外）　 ② 「形は完成するけど点数不足」の待ちをアガリ待ちと区別して出すこと　 ③ 残り枚数（手牌＋ドラ表示を差し引く）とフリテンの警告　 ④ 6枚時の捨て牌ランキング（テンパイ化＞待ち枚数＞見込める点数）　 ⑤ 危険牌予測: 場の見え牌を差し引いた山から相手の手をサンプリング推定し、ロン確率と想定損失を表示。相手が捨てた牌はその相手に確定安全（フリテン）。
